# NS Fitness Club Website

A responsive, multi-section one-page website concept for NS Fitness Club.

## Run locally
No build step is required. Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Before publishing
- Confirm exact opening and closing hours with the owner.
- Add real membership prices, durations and confirmed plan inclusions.
- Confirm which facilities and personal training services are actually available.
- Replace illustrative Unsplash stock photos with owner-provided NS Fitness Club photos.
- Confirm the Google Maps pin/address and add the owner's logo/social links if available.

## Functional elements
- Responsive navigation with mobile menu
- WhatsApp floating button and plan-specific pre-filled enquiries
- Tap-to-call and Google Maps directions
- Embedded Google map
- Click-to-expand gallery lightbox
- SEO title and description

All gym imagery is illustrative stock photography and must not be represented as actual club photos.
